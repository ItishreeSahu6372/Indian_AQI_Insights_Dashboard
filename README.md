# India AQI Analytics Dashboard

## Project Overview

This project analyzes air quality trends across Indian cities using AQI data from 2022–2025. Python was used for data cleaning, preprocessing, feature engineering, and aggregation, while Excel was used to build an interactive dashboard for visual analysis.

## Objectives

- Analyze AQI trends over time
- Identify the most polluted cities
- Analyze pollutant distribution
- Compare air quality across Indian states

## Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Filled Maps
- GitHub

## Dashboard Features

### KPI Cards
- Average AQI
- Most Polluted City
- Dominant Pollutant

### Visualizations
- AQI Trend Over Time
- Top Polluted Cities
- Pollutant Distribution
- AQI Across Indian States

## Key Insights

- AQI levels varied across different months and years.
- Byrnihat and Delhi were among the most polluted cities.
- PM10 and PM2.5 were the dominant pollutants.
- Air quality showed noticeable variation across Indian states.
